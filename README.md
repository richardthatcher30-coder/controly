# Controly

A free, open-source, ad-free, subscription-free app for controlling the screens and devices on your home network — Android TV, Google TV, Fire TV, Sony Bravia TVs, Samsung Smart TVs, and Windows PCs — all from one app, with IP camera viewing built in. Everything talks directly to your devices over your local network; nothing goes through a cloud service.

A plugin architecture (`IDevicePlugin`) means adding support for a new device type doesn't require touching the UI or any other plugin — see [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## What's here

- **Android app** (`app/`, `core/`, `plugins/`, `features/`) — the main app, in Kotlin/Jetpack Compose.
- **Windows Companion** (`windows-companion/`) — a small C#/.NET tray app that the Windows plugin talks to over WebSocket, giving mouse/keyboard/app-launcher control of a PC.
- **iOS port** (`ios/`, `iosApp/`) — an in-progress Kotlin Multiplatform port; currently an early scaffold, not yet feature-complete. See the module notes in `docs/ARCHITECTURE.md`.

## Building

**Android app:**
```bash
./gradlew :app:assembleDebug
```
Requires the Android SDK (see `local.properties`, auto-generated by Android Studio). A signed release build additionally needs `keystore/keystore.properties` (gitignored — not required for debug builds or local development).

**Windows Companion:**
```powershell
windows-companion/installer/build-installer.ps1
```
Requires the .NET SDK and, to build the installer, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

**iOS:** see the `ios-debug`/`ios-release` workflows in [`codemagic.yaml`](codemagic.yaml) for the exact build steps (Kotlin/Native framework build + Xcode archive).

## Contributing

Adding support for a new device type means implementing `IDevicePlugin` (see `core/plugin-api`) in a new `plugins/plugin-<yourdevice>` module — existing plugins (`plugin-androidtv`, `plugin-sonytv`, `plugin-samsungtv`, `plugin-windows`) are the best reference for the pattern. PRs welcome; please open an issue first for anything beyond a small fix so we can talk through approach before you invest time in it.
