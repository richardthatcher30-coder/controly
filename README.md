# HomeControl

A free, open-source, ad-free, subscription-free Android application for controlling devices around your home over the local network — Android TV, Google TV, Fire TV, Samsung Smart TVs, Windows PCs, and (later) IP cameras, smart lighting, and Home Assistant — all from one app, with a plugin architecture so the community can add support for new devices.

**Status:** Phase 1 (architecture) — see [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). No application code has been written yet; the folder structure below reflects the module layout only.

## Module layout

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the full explanation of every module, the plugin contract, the per-device communication protocols, and the roadmap.
